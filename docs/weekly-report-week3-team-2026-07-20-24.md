## 4. 문제점 / 아쉬운 점 · 개선계획

- 혼잡 예측은 과거 패턴 기반이라 대규모 집회·행사 등 돌발 상황에서 오차 가능 → 비정기 이벤트는 실시간 인원·추가 데이터 함께 활용
- 역 정보 한계: 서울교통공사 관할 역만 학습 → 서울 지하철 전 역 데이터로 보강
- 정보 수집: 과거 행사 데이터 부족 → 다양한 행사 과거 데이터를 학습에 반영
- 소셜 로그인: 이용 편의 → 카카오톡 소셜 로그인 구현·고도화
- 배리어프리: 교통약자 차별화 → 역별 상세 정보 서비스
- (구현) 혼잡 절대% 이벤트 베이스라인 오염 → AI팀 보정 모델 교체 후 재검증, UI에 예측 원인 병기
