## 4. 문제점 / 아쉬운점 / 개선계획

- **모델:** 혼잡 클래스 정확도 약 37%, 퇴근 시간대 일부 역 과소 예측 → 이벤트·집회 피처 추가 후 전체 재학습·성능 평가
- **데이터:** SPATIC 인원수 부재, KOPIS 관람객 수 없음 → SMPA·경찰민원24 매핑, 공연은 일정·시간대 변수로 보완
- **노선도 가독성:** 역명 튀는 문제, 역간 간격·라벨 가림 → 위상 레이아웃·라벨 위치 재정비, 혼잡 표시는 시안 테스트 후 확정
- **브랜치·배포:** 작업 분산 → `main` 단일 기준선 + 짧은 feature/fix 유지
- **ODsay 호출 한도:** 슬라이더마다 재호출 위험 → 검색 1회 + 혼잡도만 클라이언트 갱신
