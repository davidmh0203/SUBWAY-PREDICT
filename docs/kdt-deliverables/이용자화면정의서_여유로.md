## 전체 IA · 화면 흐름

```
[홈 #home]
   ├─ 검색 ──► [경로 결과 #results] ──► [경로 상세 #detail]
   ├─ 노선도 탭 ──► [노선도 #macro] ──► 검색 ──► [#results]
   └─ 즐겨찾기 탭 ──► [즐겨찾기 #favorites] ──(미로그인)──► [로그인 #login]
                                              └(항목 선택)──► [#results]
```

하단 탭: **홈 · 경로 · 즐겨찾기 · 노선도**  
(`경로` 탭은 마지막 결과 유지 / 상세는 결과에서 push)

## SCR-HOM — 홈 (`#home`)

### 목적
출발·도착·시간을 넣고 경로 혼잡 검색을 시작하고, 당일 정체 예보·주변 혼잡을 한눈에 본다.

### 와이어 (블록)

```
┌─────────────────────────────┐
│ 여유로          (설정/진입) │
├─────────────────────────────┤
│ 오늘의 정체 예보  [● ○ ○]→ │  ← 가로 캐러셀
│ ┌─────────────────────┐     │
│ │ 이벤트 카드          │     │
│ └─────────────────────┘     │
├─────────────────────────────┤
│ 출발  [ 역 검색          ]  │
│ 도착  [ 역 검색          ]  │
│ 시간  [ 07.16 08:30    ▼]  │
│ [ 경로 예측 검색 ]          │
│ 데모: [시청→동대문] …       │
├─────────────────────────────┤
│ 내 주변 역 혼잡 (선택)      │
│ ○○역  보통  ·  △△역 혼잡   │
├─────────────────────────────┤
│ [홈] [경로] [★] [노선도]    │
└─────────────────────────────┘
```

### UI 요소 · 동작

| ID | 요소 | 동작 |
|----|------|------|
| HOM-E01 | 정체 예보 캐러셀 | 좌우 스와이프. 첫 카드=중요 이벤트. 점/peek으로 추가 존재 암시 |
| HOM-E02 | 출발/도착 검색 | 자동완성으로 역 선택 |
| HOM-E03 | 시간 버튼 | 하단 시트에서 일시 선택 |
| HOM-E04 | 검색 CTA | `#results`로 이동, API→fallback |
| HOM-E05 | 데모 OD 칩 | 출발·도착 필드 채움 |
| HOM-E06 | 주변 역 혼잡 | 권한·API 있을 때 표시 |

### 다음 화면
- 검색 성공 → `SCR-RES`
- 설정(개발) → cong-viz (발표 범위 외)

### 비고
홈의 “자주 가는 경로” 섹션·상단 회원 아이콘은 **상시 노출하지 않음**. 회원은 즐겨찾기/로그인 흐름으로.

## SCR-RES — 경로 결과 (`#results`)

### 목적
같은 OD에 대해 **복수 경로의 혼잡·시간**을 비교하고, 최단/쾌적 중 선택한다.

### 와이어

```
┌─────────────────────────────┐
│ ←  시청 → 동대문   08:30    │
├─────────────────────────────┤
│ 시간대 혼잡 차트            │
│ ▇▇▅▃ …                      │
│ 슬라이더 ●────────○         │
├─────────────────────────────┤
│ ┌ 최단  28분 · 환승1 · ★ ┐  │
│ │ 혼잡 스트립 요약         │  │
│ └──────────────────────────┘  │
│ ┌ 쾌적  32분 · 환승1 · ★ ┐  │
│ │ …                        │  │
│ └──────────────────────────┘  │
├─────────────────────────────┤
│ [홈] [경로] [★] [노선도]    │
└─────────────────────────────┘
```

### UI 요소 · 동작

| ID | 요소 | 동작 |
|----|------|------|
| RES-E01 | 혼잡 차트 | 검색 시각 전후 추이 |
| RES-E02 | 시각 슬라이더 | 시각 변경 시 혼잡 표현 갱신 |
| RES-E03 | 경로 카드 | 시간·환승·요금·혼잡 요약, 최단/쾌적 뱃지 |
| RES-E04 | ★ 토글 | 로그인 시 즐겨찾기, 아니면 `SCR-AUTH` |
| RES-E05 | 카드 탭 | `SCR-DET` |

### 다음 화면
`SCR-DET` / `SCR-AUTH` / 탭 이동

## SCR-DET — 경로 상세 (`#detail`)

### 목적
선택한 경로의 **구간·역사 혼잡**과 **열차(편성) 혼잡**을 자세히 본다. (칸별 제외)

### 와이어

```
┌─────────────────────────────┐
│ ←  경로 상세                │
├─────────────────────────────┤
│ 타임라인 + 혼잡 스트립      │
│ 여유──보통──혼잡  레전드%   │
├─────────────────────────────┤
│ 스케매틱 [펼치기 ▼]         │
│ ●출발 ── ●환승 ── ●도착     │
│   (중간역은 접힘)           │
├─────────────────────────────┤
│ 역사 혼잡 차트 (선택)       │
├─────────────────────────────┤
│ 열차 혼잡                   │
│ 08:32 방면 · 보통 45%       │
│ 08:37 방면 · 혼잡 68%       │
├─────────────────────────────┤
│ (대안) 다음 열차 안내       │
└─────────────────────────────┘
```

### UI 요소 · 동작

| ID | 요소 | 동작 |
|----|------|------|
| DET-E01 | 혼잡 스트립 | 구간 색 표시, 레전드에 텍스트+% |
| DET-E02 | 접이식 스케매틱 | 기본=출발/도착/환승, 토글로 경유 전체 |
| DET-E03 | 열차 혼잡 리스트 | 편성 단위 (칸별 히트맵 없음) |
| DET-E04 | 대안 안내 | 조건 충족 시 노출 |

### 다음 화면
뒤로 → `SCR-RES`

### 범위 외
경로 상세 하단 미니맵 컴포넌트는 코드에만 있고 **미연결** → 본 정의서에 포함하지 않음.

## SCR-FAV — 즐겨찾기 (`#favorites`)

### 목적
자주 쓰는 OD+출발시각을 저장해 다시 조회한다.

### UI · 동작

| ID | 요소 | 동작 |
|----|------|------|
| FAV-E01 | 목록 | start→end, 시각, 라벨 |
| FAV-E02 | 항목 탭 | 해당 시각으로 재조회 → `SCR-RES` |
| FAV-E03 | 삭제 | 항목 제거 |
| FAV-E04 | 빈/비로그인 | 로그인 유도 → `SCR-AUTH` |

제약: 최대 **5**건.

## SCR-MAP — 노선도 (`#macro`)

### 목적
지도에서 역을 골라 OD를 만들고 검색한다. 서울 데이터 범위.

### 와이어

```
┌─────────────────────────────┐
│ [출발] [도착]  시간 칩들    │
│ 검색창 · 내 위치            │
├─────────────────────────────┤
│                             │
│      (인터랙티브 노선도)     │
│                             │
├─────────────────────────────┤
│ [경로 예측 검색]            │
│ [홈] [경로] [★] [노선도]    │
└─────────────────────────────┘
```

### UI · 동작

| ID | 요소 | 동작 |
|----|------|------|
| MAP-E01 | 맵 | 확대·이동, 서울 필터 역 |
| MAP-E02 | 역 탭 | 출발/도착 모드에 따라 지정 |
| MAP-E03 | 모드 버튼 | 출발↔도착 |
| MAP-E04 | 시간 마크 | 예측 기준 시각 |
| MAP-E05 | 검색 CTA | OD 완료 시 `SCR-RES` |

### 목적
즐겨찾기 등 회원 기능용 JWT 세션.

| ID | 요소 | 동작 |
|----|------|------|
| AUTH-E01 | 로그인 탭 | email/password → JWT |
| AUTH-E02 | 가입 탭 | email/nickname/password |

## 혼잡 색·등급 (공통)

| 표시 | 대략적 % | 색 역할 |
|------|----------|---------|
| 여유 | &lt;30 | 여유 |
| 보통 | 30–59 | 보통 |
| 혼잡 | 60–79 | 주의 |
| 매우혼잡 | 80–99 | 경고 |
| 극혼잡 | ≥100 | 위험 |

색만으로 구분하지 않도록 **텍스트 라벨 + %**를 레전드·리스트에 병기.
