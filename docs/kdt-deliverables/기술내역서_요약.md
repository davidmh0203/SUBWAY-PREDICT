## 1. 아키텍처 개요

```
[브라우저 React SPA @ Vercel]
        |
        +-- Supabase (PostgreSQL) ── Auth + favorite_routes  [VITE_SUPABASE_*]
        |
        +-- FastAPI @ Render (Docker) ── ODsay · 혼잡 추론 · forecast  [VITE_API_BASE_URL]
        |
        +-- Kakao Map JS (프론트 직연)
```

- **회원·즐겨찾기 (운영):** Supabase **PostgreSQL** (`auth.users`, `public.favorite_routes`, RLS)
- **경로·혼잡·예보:** FastAPI (Render 또는 로컬). LightGBM `.pkl` **추론만**
- **fallback:** Supabase env 없으면 FastAPI `/auth`, `/favorites` + **SQLite** `app.db`
- **프로덕션 FE:** Vercel. API 없으면 경로·혼잡 **mock fallback**
- 상세: [`docs/architecture-diagram.md`](../architecture-diagram.md)

## 2. 개발 환경 · 버전

### Frontend

| 항목 | 버전/내용 |
|------|-----------|
| Runtime | Node.js (개발 시 로컬 LTS) |
| Framework | React **19.2.x** |
| Bundler | Vite **8.x** |
| CSS | Tailwind CSS **4.x** (`@tailwindcss/vite`) |
| 차트 | Recharts **3.x** |
| UI primitives | Radix Dialog / Slider / Tabs / Slot |
| 아이콘 | lucide-react |
| Lint | oxlint |
| 기타 | class-variance-authority, clsx, tailwind-merge |

### Backend

| 항목 | 버전/내용 |
|------|-----------|
| Language | Python 3.x (venv) |
| Framework | FastAPI (`fastapi[standard]`) |
| HTTP client | httpx ≥ 0.27 |
| ORM / DB (fallback) | SQLAlchemy ≥ 2.0 + SQLite (로컬 JWT 경로) |
| Auth (운영) | **Supabase Auth** (Email · Kakao OAuth) |
| Auth (fallback) | bcrypt, PyJWT |
| ML | LightGBM ≥ 4.0, scikit-learn **1.7.2**, numpy, pandas |
| Config | python-dotenv |

### Database

| 항목 | 내용 |
|------|------|
| DBMS (운영) | **Supabase Managed PostgreSQL** |
| 물리 테이블 (운영) | `auth.users`, `public.favorite_routes` (UUID, RLS) |
| DBMS (fallback) | SQLite `backend/data/app.db` |
| 물리 테이블 (fallback) | `users`, `favorite_routes` (INTEGER) |
| 학습·예보 데이터 | CSV 파일 (승하차·날씨·특일·행사 등) — Postgres 미적재 |

## 6. 혼잡 표현

- 역사: 예측 혼잡률(%) → 5단계 색·라벨 (여유~극혼잡)
- 경로: 구간 스트립 + 최단/쾌적 랭킹
- 열차: **편성 단위** 리스트 (칸별 히트맵은 범위 외)
